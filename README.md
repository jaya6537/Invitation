# Srikanth & Divya — కల్యాణ ఆహ్వాన పత్రిక 🌸
### South Indian Telugu Wedding Invitation Web Application

A viral, luxury South Indian (Telugu) wedding invitation web application crafted for mobile devices, blending temple aesthetics, royal typography, falling flower petal shower animations, and the latest **"సీతా కల్యాణ వైభోగమే"** wedding soundtrack.

---

## ✨ Features
- 🌸 **Real-time Flower Petal Shower**: Realistic Jasmine (*మల్లెపూలు*), Marigold (*బంతిపూలు*), Rose (*గులాబీ రేకులు*), and Akshathalu (*అక్షింతలు*) with 3D tumble physics.
- 🎶 **Wedding Music Player**: Plays the latest *Sita Kalyana Vaibhogame* (from *Anni Manchi Sakunamule* by Mickey J. Meyer), with switchable classical Flute & Veena instrumental tracks.
- 🏛️ **Sacred Temple Aesthetic**: Hand-crafted Tirupati Balaji Tanjore artwork, Lord Ganesha invocation, and Kalyana Mandapam motifs.
- 📜 **Sumuhurtham & Panchangam**: Traditional Telugu almanac details (*స్వస్తిశ్రీ చాంద్రమాన శ్రీ క్రోధన నామ సంవత్సరం...*).
- ⏳ **Live Countdown Timer**: Real-time ticker counting down to November 15, 2026.
- 🪔 **5 Sacred Wedding Rituals**: Pellikuthuru, Snathakam, Edurukolu, Sumuhurtham & Jeelakarra-Bellam, and Talambralu.
- 📍 **Interactive Venue & Navigation**: Location card for Jubilee Hills, Hyderabad with one-click Google Maps directions and Uber ride links.
- 💌 **RSVP & Blessings Wall**: Instant interactive blessings generator with live stream.
- 📱 **Mobile-First Design**: Precision-tuned layout for smartphones.

## 🛠️ Tech Stack
- **HTML5** & Semantic Markup
- **Vanilla CSS3** (CSS custom properties, glassmorphism, responsive viewport)
- **Vanilla JavaScript** (Canvas 2D animation, IntersectionObserver, Audio API)
- **Google Fonts**: Rozha One, Pinyon Script, Marcellus, Suranna, Noto Serif Telugu, Plus Jakarta Sans, Cinzel
